# YouTube Music for Steam 0.6.8

This release brings YouTube Music playback, library, queue, search, lyrics, and Cast controls into Steam Quick Access. It is designed for SteamOS systems running Decky Loader, including Steam Deck and Steam Machine; the Deck is tested, while Steam Machine support depends on Decky Loader availability for that system.

Highlights include:

- Earlier playlist playback: start with the first playable batch while the rest loads in the background.
- Easier account setup by importing a signed-in YouTube Music session from Firefox.
- Custom playlist ordering and queue reordering, alongside alphabetical sorting.
- Fullscreen lyrics with timed following where available and temporary screen-awake protection.
- Cover-colored interface details and a slow fullscreen lava-lamp backdrop.
- Cast receiving, controller-friendly player controls, and Steam notifications for track and device changes.

Install `youtube-music-for-steam-0.6.8.zip` using Decky's **Install from ZIP** option. The `-source.zip` archive contains readable code for development. This is an unofficial community project and is not affiliated with YouTube, Google, or Valve.
